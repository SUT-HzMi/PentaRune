# PentaRune

 赫兹矩阵机器人战队Robomaster能量机关的 Flutter 蓝牙控制端

## 功能

- 按设备名扫描并连接 Hertz_DaFu
- 红/蓝方、大/小符、循环和旋转方向控制
- 实时运行日志与成绩历史
- 装甲板、边缘、矩阵和 RLogo 亮度设置
- 电机 PID 设置、电机解锁和装甲板 ID 重置
- 板卡在线状态轮询、装甲板灯板调试和电机目标转速控制
- 保留通用 BLE 扫描、服务和特征值调试页面
- 内置模拟设备，可在没有硬件时测试全部界面与运行流程

## 运行

```sh
flutter pub get
flutter run
```

真机需要授予蓝牙扫描和连接权限。协议定义见 `proto.md`。

没有设备时，在“设置”页底部的“开发选项”中开启“模拟设备”，即可进入本地调试模式。关闭开关后，应用会恢复扫描真实设备。
